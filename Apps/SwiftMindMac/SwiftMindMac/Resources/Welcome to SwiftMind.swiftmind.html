• Welcome to SwiftMind
    Welcome! This map **is** the user guide — and a live demo. Everything here is editable: select any node and press `⌘T` to add a child, drag branches around, unfold the folded ones. Notes render Markdown and even math: $e^{i\pi}+1=0$ *Deleted or broke something? Help → SwiftMind Help reinstalls a fresh copy.*
    • Start Here
      SwiftMind is a native macOS mind-mapping app. Your maps are plain `.swiftmind.html` files — they open read-only in any browser, no app required.
      • ⌘N new map · ⌘O open · File → Open Recent
      • ⇧⌘B My Brain: vaults of maps
        **My Brain** is a mind-map view of your folders. - Add Vault… registers any folder (security-scoped) - Double-click a map node to open it - Double-click a folder to fold/unfold it - Default library: the app’s sandbox Documents/SwiftMind folder for the App Store edition; user-selected vault folders can be anywhere you authorize.
      • ⌘, Settings: launch behavior, media size, note editing, vaults, agent bridge
      • Toolbar: switch canvas ⇄ outline, both stay in sync
    • Editing
      • ⌘T child · ⇧⌘T sibling · ⌫ delete · ⌘Z undo
      • Drag a node onto another to reparent
      • Double-click a title to rename; a markdown node opens the note on the node
      • ⇧⌘P pins a node · Option+drag places it freely
        Auto layout positions everything for you. **Pin** a node to freeze its spot; **Option+drag** moves the pin; **Unpin** hands it back to auto layout.
      • ⌘C/⌘X/⌘V copy whole subtrees
        Paste is smart: - Markdown bullets → nested nodes - A URL → a link node - An image → embedded in the note - HTML from other apps → plain text Every paste is one undo step.
      • Drop text, URLs, images or files right onto the canvas
      • D turns a node into a sketch you draw by hand
        Select a node and press `D` (or ⇧⌘D): it becomes a **sketch node** with a large borderless drawing board. Draw with the mouse (Apple Pencil on iPad, coming later), erase, undo — `Esc` or **Done** commits and the node shrinks to exactly your drawing, trimmed and centered. Double-click a sketch node to draw more; right-click to remove the sketch.

    • Navigate
      • Arrows or hjkl move spatially · f = follow mode
        `j`/`k` walk siblings, `h`/`l` follow the branch inward/outward. Press `f` and the canvas keeps the active node centered as you navigate. `Esc` clears focus.
      • ⌘+ / ⌘- / ⌘0 / ⌘9 zoom · pinch · ⌘-scroll · two-finger pan
      • ⌘F searches titles and notes
      • ⌘K command palette: every action + jump to node
      • Bookmark nodes, jump back from the sidebar

        • ⌘Z / ⇧⌘Z — undo / redo
        • ⌘C / ⌘X / ⌘V — copy / cut / paste nodes

    • Notes & Markdown
      Every node carries a **Markdown note**. - **Bold**, *italic*, `code`, lists > Quotes and > everything else you'd expect Inline math $\sqrt{x^2+y^2}$ and block math: $$\frac{-b \pm \sqrt{b^2-4ac}}{2a}$$ Select a node, press `E` for a floating editor to the right, `⌘E` (or double-click) to edit markdown on the node, `⌥⌘E` to pin the rendered card onto the canvas (like this one). The editor shows the formatted note while the file stays Markdown; the marks come back for the piece under the caret. The toolbar inserts an image, math, or a link. Settings (`⌘,`) → **Note editing** can instead edit **directly on an expanded card** — keep both modes while you compare.

    • Why SwiftMind
      Most mind maps live in a closed format you cannot open without that app. SwiftMind is the opposite: **the file is the product**. A map is a plain `.swiftmind.html` file — nested lists a browser can already render, a text editor can grep, git can version, and an AI agent can read and edit without a special SDK.
      • Plain HTML — nested lists, not a proprietary blob
        The model is serialized as `<ul>` / `<li>`. Open the file in Safari or Chrome and you get a readable hierarchy. No plugin, no account, no SwiftMind install required to *read*.
      • Open format: copy, git, grep, email, backup
        Treat maps like any other document. Drop them in a folder, commit them, search them with ordinary tools, attach them to mail. You are not trapped in a vendor database.
      • No lock-in — the file outlives the app
        Editing happens in SwiftMind; sharing does not. Send someone the `.swiftmind.html` and they can read it today. If you ever leave the app, the knowledge is still HTML.
      • Built for AI agents: CLI, MCP, one undo step
        `swiftmind` reads and batch-edits map files. `swiftmind mcp` drives the *open* map over a local socket — no network. Agent edits land as **one ⌘Z**. Agents work on the same HTML humans share.
      • Offline by design: no account, no cloud, no telemetry
        The app is sandboxed and has **no network entitlement**. Maps stay on disks you choose. Optional agent bridge is a Unix socket on this machine only.
      • Native editor — Markdown, math, formulas, still just HTML
        Canvas and outline, notes with Markdown and a LaTeX subset, live formulas that are *derived* (never stored, never executed as code). Power stays in the file format, not a hidden database.
      • This node is an orphan — filter `orphan` to find leaves nothing points at
        An **orphan** has no children, no links out, and nobody links in. Filter `orphan` (highlight) to see them. `swiftmind doctor` lists the same class of issues.
      • This node has a dangling node-link — filter `dangling`
        Node links that point at a deleted or never-created id are **dangling**. Filter `dangling` or run Doctor from ⌘K.

    • Automation & Agents
      • swiftmind CLI: read, find, batch-edit map files
        `swiftmind read map.swiftmind.html` prints the map as JSON; `batch` applies JSON ops all-or-nothing; edits are refused if the file changed on disk in between. The app hot-reloads external changes.
      • swiftmind mcp: agents drive the live app
        A local Unix-socket bridge (no network) lets an AI agent read and edit the map you have open — as **one undo step** per batch. Toggle it in Settings (⌘,) → Agent.
      • Bulk actions: restyle every filter match at once
      • Sandboxed JavaScript from the ⌘K palette
        Scripts use the `mindmap` API to record *intents* — applied as one undoable batch only if the script finishes cleanly. No network, file, or process access exists inside the sandbox.
