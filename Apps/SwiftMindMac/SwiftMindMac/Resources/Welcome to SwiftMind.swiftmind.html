• Welcome to SwiftMind
    Welcome! This map **is** the user guide — and a live demo. Everything here is editable: select any node and press `⌘T` to add a child, drag branches around, unfold the folded ones. Notes render Markdown and even math: $e^{i\pi}+1=0$ *Deleted or broke something? Help → SwiftMind Help reinstalls a fresh copy.*
    • Start Here
      SwiftMind is a native macOS mind-mapping app. Your maps are plain `.swiftmind.html` files — they open read-only in any browser, no app required.
      • ⌘N new map · ⌘O open · File → Open Recent
      • ⇧⌘B My Brain: vaults of maps
        **My Brain** is a mind-map view of your folders. - Add Vault… registers any folder (security-scoped) - Double-click a map node to open it - Double-click a folder to fold/unfold it - Default library: `~/Documents/SwiftMind`
      • ⌘, Settings: launch behavior, vaults, agent bridge
      • Toolbar: switch canvas ⇄ outline, both stay in sync
    • Editing
      • ⌘T child · ⇧⌘T sibling · ⌫ delete · ⌘Z undo
      • Drag a node onto another to reparent
      • Double-click a title to rename; a markdown node opens the note on the node
      • ⇧⌘P pins a node · Option+drag places it freely
        Auto layout positions everything for you. **Pin** a node to freeze its spot; **Option+drag** moves the pin; **Unpin** hands it back to auto layout.
      • ⌘C/⌘X/⌘V copy whole subtrees
        Paste is smart: - Markdown bullets → nested nodes - A URL → a link node - An image → embedded in the note - HTML from other apps → plain text Every paste is one undo step.
      • Drop text, URLs, images or files right onto the canvas
    • Navigate
      • Arrows or hjkl move spatially · f = follow mode
        `j`/`k` walk siblings, `h`/`l` follow the branch inward/outward. Press `f` and the canvas keeps the active node centered as you navigate. `Esc` clears focus.
      • ⌘+ / ⌘- / ⌘0 zoom · pinch · ⌘-scroll · two-finger pan
      • ⌘F searches titles and notes
      • ⌘K command palette: every action + jump to node

    • Formulas — live results
      A small, safe expression DSL — never arbitrary code. Results are **derived**: they recompute live and are never stored in the file. Broken formula? You get `#ERR: reason` inline, nothing crashes. DSL: `attr("cost")`, `sum|avg|min|max(children, attr: "cost")`, `count(children)`, `progress()`, arithmetic, comparisons, `and/or/not`, `if(c, t, e)`.

    • Automation & Agents
      • swiftmind CLI: read, find, batch-edit map files
        `swiftmind read map.swiftmind.html` prints the map as JSON; `batch` applies JSON ops all-or-nothing; edits are refused if the file changed on disk in between. The app hot-reloads external changes.
      • swiftmind mcp: agents drive the live app
        A local Unix-socket bridge (no network) lets an AI agent read and edit the map you have open — as **one undo step** per batch. Toggle it in Settings (⌘,) → Agent.
      • Bulk actions: restyle every filter match at once
      • Sandboxed JavaScript from the ⌘K palette
        Scripts use the `mindmap` API to record *intents* — applied as one undoable batch only if the script finishes cleanly. No network, file, or process access exists inside the sandbox.
